Pinyin MP3 files used by the local pronunciation fallback.

Source: https://github.com/davinfifield/mp3-chinese-pinyin-sound
License: Unlicense / public domain. See `LICENSE`.

Only the syllables currently used by the app's pinyin practice flows are
vendored here to keep the GitHub Pages build small. Filenames follow the
upstream format: plain pinyin plus tone number, for example `ma1.mp3`.
